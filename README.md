# Provisa Writers — Standalone Template 2

This folder contains the live preview version of the standalone Provisa Writers Template 2 website. It is a Vite/React static site and can be deployed to Vercel or any static host.

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

## Included in this prototype

- Editorial Template 2 landing page with responsive anchor navigation.
- A focused homepage with five primary sections: About Us, Meet the Team, Our Services, Results, and Contact Us.
- A single **Our Services** section that combines services and who we help.
- Services requested by the client: Profile Assessment, Profile Building, Case preparation (EB1A and EB2-NIW), and Strategy Development.
- Team section with clearly labelled placeholder portraits and a touch-friendly carousel.
- Results section with recognitions framed as proof of global relevance and a stylised United States visa visual labelled as a non-government placeholder.
- Blog and FAQ in a slide-out field-guide sidebar rather than as primary homepage sections.
- Browser-based `/pwadmin` blog editor with image upload, edit, delete, publish date and expiry date controls.
- Browser-based staff directory editor with add, edit, delete, role, biography, and portrait controls.
- Contact form that prepares an email to `info@provisawriters.com`.
- Footer contact row with “Shout us on WhatsApp”, Instagram, LinkedIn, and email links supplied by the client.

The admin editor and contact flow are intentionally prototype-only. See `site-building-prompts.md` for the full history, temporary access details, and production handoff notes.
